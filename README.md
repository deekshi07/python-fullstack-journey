# Python Fullstack Journey 🚀

A comprehensive repository for mastering Python full-stack development, including core Python, databases, backend frameworks, modern frontend, DevOps, and real-world projects.

## 📂 Repository Structure

- **`01-python/`** — Python basics, data structures, OOP, functional programming, and daily practice.
  - `day01/` — Hello World, Variables, Data Types, Operators, Input/Output, Practice Exercises.
  - `day02/` — Control Flow & Loops.
  - `day03/` — Functions & Modules.
- **`02-sql/`** — Relational database modeling, queries, PostgreSQL & MySQL.
- **`03-django/`** — Full-featured web applications with Django & ORM.
- **`04-django-rest/`** — REST APIs, serializers, viewsets, authentication & JWT.
- **`05-flask/`** — Microservices and lightweight web APIs with Flask.
- **`06-fastapi/`** — Asynchronous high-performance APIs with FastAPI and Pydantic.
- **`07-react/`** — Frontend interfaces, React hooks, routing, state management.
- **`08-devops/`** — Docker, CI/CD GitHub Actions, Nginx, cloud deployments.
- **`09-projects/`** — Production-ready capstone full-stack applications.
